# 🧀 PIECE
가게 안의 유휴공간을 임대하는 초단기 샵인샵(Shop-in-Shop) 매칭 플랫폼


## 📋 프로젝트 소개
Piece는 기존 부동산 시장의 높은 보증금과 장기 계약 관행에서 벗어나, 누구나 부담 없이 오프라인 판매 거점을 확보할 수 있도록 돕습니다. 공간주에게는 월세 부담 완화를, 메이커에게는 팝업 스토어 기회를 제공함으로써 골목 상권 내에서 **공간의 재발견**과 **경제적 상생**을 실현하는 온-오프라인 연계(O2O) 웹 서비스를 지향합니다.

- 자영업자의 고충 (공급자): 경기 침체와 임대료 상승으로 인해 고정비 부담이 커지고 있습니다. 매장 내 활용되지 않는 빈 공간(카운터 옆, 빈 벽면, 남는 테이블 등)을 수익화할 방법이 필요합니다.
- 소규모 창작자/셀러의 니즈 (수요자): 나만의 브랜드를 알리고 싶지만, 높은 보증금과 장기 계약의 부담으로 인해 오프라인 매장 오픈은 진입 장벽이 너무 높습니다. 단기 팝업 스토어나 소량 위탁 판매를 할 수 있는 공간이 절실합니다.
- 기존 시장의 문제점: 기존 부동산 플랫폼은 '매장 전체' 임대 위주이며, 1평 미만의 초소형 공간을 단기로 거래할 수 있는 전문 플랫폼이 부재합니다.
- 해결책: 신뢰할 수 있는 이웃 가게의 남는 공간을 저렴하게 빌려주는 '공간 공유 매칭 서비스'를 통해 상생 생태계를 구축하고자 합니다.
